# Disaster Relief Planning

A simple Python program that creates a basic disaster relief action plan based on the type of disaster, location, number of people affected, and available supplies.

## Project Goal
This project helps organize emergency response actions in a clear and simple way. It is designed for quick planning during disasters such as floods, earthquakes, fires, and storms.

## Features
- Identifies the disaster type
- Shows a summary of the emergency situation
- Lists priority actions to take
- Assigns basic team roles
- Helps track people affected and available supplies

## How to Run
1. Make sure Python is installed on your computer.
2. Save the code in a file named `disaster_relief_planning.py`
3. Open a terminal or command prompt
4. Run:

```bash
python disaster_relief_planning.py
